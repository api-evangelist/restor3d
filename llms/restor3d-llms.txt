# restor3d

> restor3d is a Durham, North Carolina medical device manufacturer, founded in 2017 as a Duke
> University spinout, that designs and 3D-prints personalized musculoskeletal implants and the
> single-use instrumentation that accompanies them. It is an FDA-regulated device maker, not a
> software vendor.

Generated by API Evangelist on 2026-08-26 from this repository's apis.yml and probed artifacts,
because https://www.restor3d.com/llms.txt returns HTTP 404. This file is a third-party profile and
is not published by restor3d.

## What restor3d makes

- Personalized, patient-matched total ankle, total knee, total hip and shoulder reconstruction
  systems, plus foot-and-ankle and spine fixation devices.
- Laser powder bed fusion printing of medical-grade titanium (Ti6Al4V ELI) and cobalt-chrome,
  including osseointegrative lattice surfaces.
- AI-driven surgical planning and design-automation software used internally to produce
  patient-specific implants from patient imaging. This software is not offered as a product,
  a platform or an API.

## The one machine-readable surface that does exist

restor3d's corporate marketing website runs WordPress, which serves a real REST API and a real
Model Context Protocol endpoint. This is site-content infrastructure, NOT a product API.

- REST index: https://www.restor3d.com/wp-json/ (HTTP 200, 353 routes across wp/v2,
  wp-abilities/v1, mcp, and SEO/caching plugin namespaces). Public GET routes cover pages, posts,
  event, resource, procedure, product-family, product-category, asset-type and content-type.
- MCP server: https://www.restor3d.com/wp-json/mcp/mcp-oauth-server — live, OAuth-gated. A
  tools/list POST returns HTTP 401 mcp_unauthorized, so the tool set is not publicly readable.
- OAuth authorization server metadata: https://www.restor3d.com/.well-known/oauth-authorization-server (200)
- OAuth protected resource metadata: https://www.restor3d.com/.well-known/oauth-protected-resource (200)
- Single scope: `mcp`. PKCE S256 required. Public clients, client-ID metadata documents.
- Rate limits: none published. robots.txt sets Crawl-delay: 10. A Cloudflare edge returns 403 to
  non-browser User-Agents on /wp-json/* paths.
